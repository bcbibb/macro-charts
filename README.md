# macro-charts

The published page from a private pipeline: 21 US macro indicators from FRED,
the Treasury yield curves, and Yahoo, rebuilt every weekday morning.

`index.html` is generated and self-contained — the data is embedded, so nothing
is fetched at view time. Do not edit it by hand; it is overwritten on each run.

Live at https://bcbibb.github.io/macro-charts/
